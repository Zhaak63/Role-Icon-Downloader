Role Icon Downloader

Récupère les icônes de rôles ou les emojis d'un serveur Discord dans un ZIP.

Le token reste dans ton navigateur et n'est envoyé qu'à discord.com. Attention : un token utilisateur donne accès à tout le compte. Ne le partage jamais, et l'utiliser en dehors de l'app Discord va contre ses conditions d'utilisation (risque de sanction du compte).

Comment trouver mon token ?
  1. Ouvre l'application Discord de bureau, ou connecte-toi sur discord.com/app.
  2. Ouvre les outils de développement avec F12 ou Ctrl + Shift + I, puis va dans l'onglet Console.
  3. Si le collage est bloqué, tape allow pasting puis appuie sur Entrée.
  4. Colle le code ci-dessous et appuie sur Entrée : 
    {webpackChunkdiscord_app.push([[Math.random()],{},e=>{e.b&&(m=Object.values(e.c))}]);let e=m.find((e=>!e?.exports?.messagesLoader&&e?.exports?.default?.getToken))?.exports?.default?.getToken?.();e?console.log(`"${e}"`):console.warn("Token not found.")}
  5. Ton token s'affiche en bas de la console. Copie ce qui se trouve entre les guillemets "" et colle-le dans le champ ci-dessus.

Ce code lit ton token dans ta propre session et l'affiche dans ta console, rien d'autre. Ne colle jamais dans la console un code que tu ne comprends pas ou qu'on t'a envoyé en message privé : il pourrait voler ton compte. Si le message « Token not found » apparaît, Discord a probablement changé son fonctionnement et ce code ne marche plus.
